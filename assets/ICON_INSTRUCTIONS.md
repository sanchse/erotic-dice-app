# Instrucciones para crear el icono de la app

## Necesitas crear un archivo app_icon.png de 512x512 píxeles

### Opción 1: Convertir el SVG creado
1. Abre el archivo `assets/app_icon.svg` en un editor de imágenes
2. Expórtalo como PNG de 512x512 píxeles
3. Guárdalo como `assets/app_icon.png`

### Opción 2: Crear tu propio diseño
El icono debe:
- Ser de 512x512 píxeles
- Tener fondo circular o cuadrado con esquinas redondeadas
- Usar colores rosados/rojos (#FF6B9D, #E91E63)
- Incluir elementos de dados
- Ser visible a diferentes tamaños

### Opción 3: Usar herramientas online
- Canva: Buscar "app icon" template
- Figma: Crear diseño de 512x512
- Convertidor SVG to PNG online

### Después de crear el PNG:
Ejecuta: `dart run flutter_launcher_icons`
